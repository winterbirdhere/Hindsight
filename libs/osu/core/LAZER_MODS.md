# Lazer mod implementation notes

The mod implementation was checked against official osu!lazer commit
[`48c4800e3ae4ee752452cdff83bd3787ccf3105f`](https://github.com/ppy/osu/tree/48c4800e3ae4ee752452cdff83bd3787ccf3105f)
on 2026-09-04. The existing local audit checkout was at
`e0279920b64c738021b05f501941c8aa65e6b589`; relevant code was compared with current upstream before implementation.

- [`OsuModClassic`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game.Rulesets.Osu/Mods/OsuModClassic.cs): all five settings default to true. Disabling slider-head accuracy and choosing Classic note lock are independent switches. Tail sample and circle fade settings are exposed for the presentation layer. Rewind uses recorded replay health; it does not independently reconstruct health drain.
- [`DrawableSliderHead`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game.Rulesets.Osu/Objects/Drawables/DrawableSliderHead.cs), [`SliderTailCircle`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game.Rulesets.Osu/Objects/SliderTailCircle.cs), and [`DrawableSlider`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game.Rulesets.Osu/Objects/Drawables/DrawableSlider.cs): Classic heads award large ticks; tails award small ticks; the parent awards the proportional 300/100/50/miss. The parent resolves at or after the actual end, once the tail has resolved.
- [`SliderInputManager`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game.Rulesets.Osu/Objects/Drawables/SliderInputManager.cs): Classic keeps native tracking, late-head catch-up and tail leniency. It does not use the stable evaluator or stable's legacy final checkpoint.
- [`LegacyHitPolicy`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game.Rulesets.Osu/UI/LegacyHitPolicy.cs): blocks unresolved previous top-level objects when their end plus 3 ms precedes the target start. Positive stacks ignore input without shaking, and slider heads continue consuming overlapping input until their parents finish.
- [`ScoreProcessor`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game/Rulesets/Scoring/ScoreProcessor.cs) and [`HitResult`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game/Rulesets/Scoring/HitResult.cs): large ticks contribute 30 accuracy points and affect combo; small ticks contribute 10 and do not affect combo. Classic's parent provides the final combo increment.
- [`OsuModDifficultyAdjust`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game.Rulesets.Osu/Mods/OsuModDifficultyAdjust.cs), [`ModDifficultyAdjust`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game/Rulesets/Mods/ModDifficultyAdjust.cs), and [`DifficultyBindable`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game/Rulesets/Mods/DifficultyBindable.cs): omitted values retain map defaults. Native deserialization accepts extended hard bounds even when `extended_limits` is omitted, and retains fractional input. DA takes precedence if invalid data also contains incompatible HR/EZ. Difficulty is applied before object geometry and stacking.
- [`ModDoubleTime`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game/Rulesets/Mods/ModDoubleTime.cs), [`ModHalfTime`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game/Rulesets/Mods/ModHalfTime.cs), and [`ModRateAdjust`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game/Rulesets/Mods/ModRateAdjust.cs): `speed_change` changes the clock, not stored beatmap or replay timestamps. DT uses 1.01–2.00 (default 1.50), HT 0.50–0.99 (default 0.75), at 0.01 precision. DT/HT pitch adjustment defaults off; NC/DC default on.

Classic slider-head analysis events retain their timing for hit samples and carry `affectsAccuracy: false`. They are excluded from accuracy judgement totals, but successful heads still contribute to UR: lazer's [`AffectsUnstableRate`](https://github.com/ppy/osu/blob/48c4800e3ae4ee752452cdff83bd3787ccf3105f/osu.Game/Rulesets/Scoring/HitEventExtensions.cs) checks for nonempty hit windows and a hit result, not accuracy eligibility. Missed heads also emit a `SliderComponentMiss` of type `HEAD`. Native Classic slider parents appear as normal scoring hit-object events. Stable event and scoring behavior is unchanged.

Validation: the complete osu-core suite passes (140 tests), including 23 new settings, geometry, scoring, note-lock, replay seeking, and stable-regression checks. Core TypeScript compilation passes. Replay simulation retains the existing approximation of cursor movement between recorded frames; the mods do not change replay sampling fidelity.
