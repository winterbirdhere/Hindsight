# Reporting a Hindsight issue

A public issue tracker or support destination has not yet been confirmed. Keep reports locally until a destination is announced; the original Rewind project's contacts are not an assumed Hindsight support channel.

A useful report can include:

- Exact Hindsight version (this preview: 0.1.0-preview.1), Windows version and whether the package is x64; include the downloaded archive checksum if available.
- Steps to reproduce, expected behavior and what happened instead.
- Whether the source is Stable local scores, Replays, native lazer or an explicit import; the selected analysis profile and relevant mods.
- Whether the issue repeats after a normal restart, plus any error message.
- An optional screenshot, short recording or relevant sanitized log excerpt.

For a playback or analysis discrepancy, include the approximate replay time and distinguish saved statistics from calculated values. Unavailable Result/FC can be a [documented evidence limitation](KNOWN-LIMITATIONS.md#result-fc-and-calculated-metrics); report unexpected changes without changing the underlying replay to force a result.

Logs, screenshots and replay files can reveal player names, personal paths and other private information. Redact what is unnecessary, and share replays or beatmap/media files only when you have permission. Do not post an entire profile, osu! database, credentials or environment files. Sharing diagnostics is optional and deliberate; these instructions do not upload anything automatically.

Back up the profile before trying a workaround. See [data and backup guidance](DATA-AND-BACKUP.md). Do not disable Windows security protections to test an unsigned preview.
